🔐 Secure File Sharing System

A full-stack web application for uploading and managing files through a simple web interface.

Overview

The Secure File Sharing System is designed to provide a convenient interface for file management, with a frontend built using HTML, CSS, and JavaScript and a backend powered by Node.js and Express.js.

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose (if used in the project)

Features

- User registration and login interface
- File upload functionality
- File management and deletion
- Backend API integration
- Database connectivity using MongoDB

Only retain features that are implemented and working in the current version.

Installation and Setup

1. Clone the repository:
   
   git clone https://github.com/Kumari-Ridhi/Secure-File-Sharing-System.git

2. Navigate to the project directory:
   
   cd Secure-File-Sharing-System

3. Install backend dependencies:
   
   cd backend
   npm install

4. Configure the required environment variables in "backend/.env". Never upload this file to GitHub.

5. Start the backend using the appropriate command defined in "backend/package.json".

6. Open "index.html" in a browser or use your configured frontend development server.
